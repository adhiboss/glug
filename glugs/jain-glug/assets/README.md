# JAIN GLUG Assets Directory

This directory stores downloadable resources, documents, presentations, and branding assets for JAIN GLUG (Faculty of Engineering and Technology, Jain University).

## Directory Structure
- `assets/` - Static downloadable materials (e.g., posters, presentation decks, event flyers).
- `images/` - Web images, FOSS tool logos (`images/foss/`), and institutional partner logos (`fsmk-logo.png`, `jain-fet-logo.png`).

## Guidelines for Adding Assets
1. **File Formats**: Prefer SVG or optimized PNG for graphics/illustrations. For documents, use PDF or Markdown.
2. **Relative Paths**: Always reference assets using relative paths (e.g., `assets/filename.pdf` or `./assets/filename.pdf`). Never use leading slashes (e.g., `/assets/`) because the website is served under the `/jain-glug/` subpath on `https://glugs.fsmk.org/jain-glug/`.
3. **File Size**: Keep images and documents optimized (under 500 KB per asset where feasible) to ensure fast load times on campus networks and mobile devices.
4. **License**: Ensure all uploaded assets respect Free & Open Source principles and Creative Commons licensing.
